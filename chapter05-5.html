Chapter 5.5

Images & Sounds

Sprites, backgrounds, sound effects, and music — plus the two keywords that make loading files work.

Up to now, every pixel on your canvas has come from shapes you drew with code. That's powerful, but real games and art pieces also use pictures and sound: a hand-drawn character, a photo for a background, a pop when you click, music that loops. This short chapter shows you how to bring those files into a sketch.

Why is it "5.5"? Because it leans on Chapter 5. Loading a file needs a special kind of setup() function, and sounds usually play from functions like mousePressed(). You know functions now — so you're ready.

This book uses p5.js 2.x Every example here runs on p5.js 2.4, the newest version. Loading files changed in p5.js 2.0, so if you find an older tutorial or video that uses a function called preload(), that's the old p5.js 1.x way. It won't work here — use the async/await style this chapter teaches. In the p5.js Web Editor, check that your sketch is set to a 2.x version.

Where your files live #

A sketch can only use a file it can reach. In the p5.js Web Editor, that means uploading the file into your sketch: open the file list beside your code, use the + menu to make a folder called assets, then upload your picture or sound into it. On a website, it means putting the file in a folder next to your HTML page.

Then you refer to the file by its path — the folder and filename, in quotes:

'assets/rocket.png'        // a file named rocket.png inside a folder named assets

All the examples in this book load files from the textbook's own assets/media/ folder, so you'll see paths like 'assets/media/rocket.png'.

TypeUse it forGood to know
PNGCharacters, icons, spritesSupports transparency — no white box around your character.
JPGPhotos and backgroundsSmaller files, but no transparency.
GIFSimple animationsp5 plays animated GIFs automatically.
MP3Sound effects and musicWorks in every browser. Your best default.
WAVShort sound effectsWorks everywhere, but files are much bigger.
Filenames are case-sensitive 'Rocket.PNG' and 'rocket.png' are different files to a web server. Your sketch might work on your computer and break once it's online. Easy habit: name every file in lowercase, with no spaces.

Loading takes time: async and await #

Here's the new idea. Drawing a circle happens instantly. Loading a file doesn't — the browser has to go get it, and that might take a split second or a few seconds on slow Wi-Fi. Your code needs to wait for the file before using it.

Think of ordering at a restaurant counter. You order, and they hand you a buzzer. The buzzer isn't your food — it's a promise that food is coming. You wait for it to buzz, then you eat. In JavaScript, loadImage() hands you the buzzer, and await means "wait for the buzz."

let rocket;

async function setup() {
  createCanvas(400, 400);
  rocket = await loadImage('assets/media/rocket.png');
}

Two new keywords, and they always come as a pair:

  • async goes in front of function setup(). It marks setup as a function that's allowed to wait.
  • await goes in front of loadImage(...). It pauses setup() right there until the file has arrived. Then rocket holds the actual image.

p5 is smart about this: draw() doesn't start until setup() has completely finished. So by the time draw() runs, every file you awaited is ready to use.

No await without async If you write await inside a function that isn't marked async, the sketch won't run at all. You'll get an error like await is only valid in async functions. The fix is the word async in front of function setup().

Drawing an image #

Once the image is loaded, image() draws it. The simplest version takes the image and an x, y position — the image's top-left corner, just like rect().

let rocket;

async function setup() {
  createCanvas(400, 400);
  rocket = await loadImage('assets/media/rocket.png');
}

function draw() {
  background(30, 30, 60);
  image(rocket, 150, 120);
}

Every loaded image knows its own size: rocket.width and rocket.height. Add two more numbers to image() to draw it at a different size: image(img, x, y, w, h). Multiplying both the width and height by the same amount keeps the image from looking squished.

This sketch combines that with a loop from Chapter 4 to draw four rockets, each bigger than the last. Notice it draws everything inside setup() — there's no draw() at all, because nothing moves.

let rocket;

async function setup() {
  createCanvas(400, 400);
  rocket = await loadImage('assets/media/rocket.png');
  background(30, 30, 60);

  let x = 10;
  for (let i = 1; i <= 4; i++) {
    let w = rocket.width * i * 0.35;
    let h = rocket.height * i * 0.35;
    image(rocket, x, 380 - h, w, h);
    x = x + w + 10;
  }
}
Try it Press Edit and change 0.35 to 0.2. Then try making only the width change (rocket.width * i * 0.35 but a fixed height) and see what a squished rocket looks like.

Centering images and following the mouse #

Just like rectMode(CENTER), there's imageMode(CENTER). After you call it, the x, y you give image() becomes the center of the picture. That's exactly what you want when an image follows the mouse.

This sketch also loads a second image for the background. Drawing a background image that fills the whole canvas does the same job as background() — it wipes the old frame away.

let rocket;
let stars;

async function setup() {
  createCanvas(600, 400);
  stars = await loadImage('assets/media/stars.jpg');
  rocket = await loadImage('assets/media/rocket.png');
  imageMode(CENTER);
}

function draw() {
  image(stars, width / 2, height / 2);   // the background
  image(rocket, mouseX, mouseY);          // the rocket follows you
}

Move your mouse over the sketch. Notice there's no white box around the rocket — the PNG's transparent pixels let the stars show through.

Tinting images #

tint() is like fill() for images: it changes the color of every image drawn after it. One number between 0 and 255 after the color makes the image see-through. noTint() turns tinting off again.

let rocket;
let stars;

async function setup() {
  createCanvas(600, 400);
  stars = await loadImage('assets/media/stars.jpg');
  rocket = await loadImage('assets/media/rocket.png');
  imageMode(CENTER);
}

function draw() {
  image(stars, width / 2, height / 2);

  tint(255, 140, 140);        // reddish
  image(rocket, 120, 200);

  tint(140, 255, 180);        // greenish
  image(rocket, 260, 200);

  tint(255, 90);              // full color, but see-through
  image(rocket, 400, 200);

  noTint();                   // back to normal
  image(rocket, 520, 200);
}
tint() sticks around Just like fill(), a tint() stays on for everything drawn after it — including your background image on the next frame. If your whole sketch suddenly turns pink, look for a missing noTint().

Making an image move #

An image is drawn at whatever numbers you give it — so put variables there and change them, exactly like the moving circles from Chapters 2 and 3. Here, the rocket flies upward, and an if statement sends it back to the bottom once it's off the screen.

let rocket;
let stars;
let x = 300;
let y = 400;

async function setup() {
  createCanvas(600, 400);
  stars = await loadImage('assets/media/stars.jpg');
  rocket = await loadImage('assets/media/rocket.png');
  imageMode(CENTER);
}

function draw() {
  image(stars, width / 2, height / 2);
  image(rocket, x, y);
  y = y - 3;

  // Off the top? Start again at the bottom, somewhere new.
  if (y < -rocket.height) {
    y = height + rocket.height;
    x = random(50, width - 50);
  }
}

Adding sound with p5.sound #

Sound lives in a separate add-on library called p5.sound. In this textbook it loads automatically whenever your sketch uses sound. In the p5.js Web Editor, make sure the p5.sound library is turned on for your sketch. On your own web page, add a second <script> tag right after p5.js:

<script src="https://cdn.jsdelivr.net/npm/p5@2.4.0/lib/p5.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/p5.sound@0.4.2/dist/p5.sound.min.js"></script>

Loading a sound works exactly like loading an image — await inside async function setup():

pop = await loadSound('assets/media/pop.mp3');

There's one big rule for sound on the web: browsers won't play any sound until the person interacts with the page. That rule exists so websites can't blast audio at you the moment they open. So we play sounds from functions that run when the user does something — like mousePressed(), which p5 calls every time you click.

let pop;
let ringX = 200;
let ringY = 200;
let ringSize = 0;

async function setup() {
  createCanvas(400, 400);
  pop = await loadSound('assets/media/pop.mp3');
}

function draw() {
  background(30, 30, 60);
  noStroke();
  fill(255);
  textAlign(CENTER);
  text('Click anywhere!', width / 2, 30);

  noFill();
  stroke(237, 34, 93);
  strokeWeight(4);
  circle(ringX, ringY, ringSize);
  ringSize = ringSize + 6;
}

function mousePressed() {
  pop.play();
  ringX = mouseX;
  ringY = mouseY;
  ringSize = 0;
}

Press Run, then click inside the sketch. (Your volume needs to be up!)

pop.play() has a dot in the middle. You can read it as "hey pop, play yourself." The sound variable comes with its own built-in commands. You'll learn exactly how that works in Chapter 6.

Playing, stopping, and looping #

A loaded sound comes with these commands:

CommandWhat it does
sound.play()Starts playing
sound.stop()Stops and rewinds to the beginning
sound.pause()Stops, but remembers where it was
sound.isPlaying()Gives back true or false — great inside an if
sound.loop(true)Turns on repeating, so it starts over when it ends
sound.amp(0.5)Sets the volume, from 0 (silent) to 1 (full)
sound.rate(1.5)Plays faster and higher (0.5 is slower and lower)

This one uses an if/else with isPlaying() so a click toggles the music on and off, and map() turns the mouse's height into a volume.

let beat;

async function setup() {
  createCanvas(400, 400);
  beat = await loadSound('assets/media/beat.mp3');
  beat.loop(true);    // repeat at the end (this does NOT start it)
}

function draw() {
  background(30, 30, 60);

  // Top of the canvas = loud, bottom = quiet
  let volume = constrain(map(mouseY, height, 0, 0, 1), 0, 1);
  beat.amp(volume);

  noStroke();
  fill(255);
  textAlign(CENTER);
  if (beat.isPlaying()) {
    text('Move up and down to change the volume', width / 2, 30);
    fill(237, 34, 93);
    rect(170, height - volume * 300 - 40, 60, volume * 300);
  } else {
    text('Click to play the beat', width / 2, 30);
  }
}

function mousePressed() {
  if (beat.isPlaying()) {
    beat.stop();
  } else {
    beat.play();
  }
}
loop(true) doesn't press play In the newest p5.sound, loop(true) only switches repeating on. You still have to call play(). Older tutorials use sound.loop() to start music and setVolume() for volume — in p5.js 2.x, use play() and amp() instead.

Making sounds from scratch #

You don't need a sound file to make noise. An oscillator creates a tone with code, the same way ellipse() creates a circle without a picture file. Its frequency — how many times per second the sound wave vibrates, measured in Hertz (Hz) — sets how high or low the note is.

This sketch turns your mouse into a simple musical instrument. Don't worry about the word new on line 6 yet — that's Chapter 6's big topic. For now, read it as "make me an oscillator."

let osc;
let playing = false;

function setup() {
  createCanvas(400, 400);
  osc = new p5.Oscillator('sine');
  osc.amp(0.3);
}

function draw() {
  background(30, 30, 60);

  // Left = low note, right = high note
  let pitch = map(mouseX, 0, width, 200, 1000);
  osc.freq(pitch);

  noStroke();
  fill(255);
  textAlign(CENTER);
  if (playing) {
    text(round(pitch) + ' Hz', width / 2, 30);
    fill(237, 34, 93);
    circle(mouseX, height / 2, 40);
  } else {
    text('Click to turn the sound on', width / 2, 30);
  }
}

function mousePressed() {
  if (playing) {
    osc.stop();
  } else {
    osc.start();
  }
  playing = !playing;   // flip true <-> false
}

Since nothing is loaded from a file, there's no async or await here. The click rule still applies, though: the oscillator starts inside mousePressed().

Common Beginner Mistakes #

Forgetting await rocket = loadImage(...) without await doesn't crash — and that's what makes it sneaky. rocket holds the "buzzer," not the image, so image() silently draws nothing. If your image just isn't showing up, check for await first.
Forgetting async await inside a plain function setup() stops the whole sketch with an error. Put async in front of function.
Copying preload() from an old tutorial In p5.js 1.x, files were loaded in a function called preload(). p5.js 2.x never calls preload(), so the code inside it simply never runs — no error, just missing images. Move the loading into async function setup() with await.
A wrong path or filename A typo, the wrong folder, or the wrong capitalization means the browser can't find your file, and p5 will tell you there was a problem loading your file. Compare the path in your code with the actual folder and filename, letter by letter.
Expecting sound before a click Calling play() in setup() won't make a sound — the browser blocks it until the user clicks or presses a key. Start sounds from mousePressed() or keyPressed().
